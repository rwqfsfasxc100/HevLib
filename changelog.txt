1=* Added `Threading` class.
1.1=* This adds a handful of functions that lets code execution be arbritrarily moved to extra threads.
1.2=* Useful for cutting down a batch of several heavy functions.
1.3=* Threads are limited to your CPU's logical core count minus 2. CPUs with Hyper-Threading enabled will be considered.
1.4=* Can be functionally disabled with the `Single-thread only` config option
1.5=* `__request_single_thread` -> Array
1.5.1=* Adds a single function call to the thread queue
1.5.2=* This function blocks execution until the function call has been completed
1.5.2.1=* All yields will be processed before execution returns to the caller
1.5.3=* `operation` -> (Dictionary) data regarding the function call requests
1.5.3.1=* `object` -> (Object) the object to call the function on
1.5.3.2=* `method` -> (String) the function to be called from the object
1.5.3.3=* `args` -> (Array) any arguments that the function accepts.
1.5.4=* Returns an array containing a single entry for the return value of the function
1.5.4.1=* This is to keep all outputs of threading functions consistent
1.5.4.2=* Any function calls that fail or return void will have a null return value
1.6=* `__request_multiple_threads` -> Array
1.6.1=* Adds an arbitrary number of function calls to the thread queue
1.6.2=* This function blocks execution until all queued function calls have been completed
1.6.3=* `operations` -> (Array[Dictionary]) array of dictionaries for function call requests
1.6.3.1=* Formatting of each dictionary is equivalent to `__request_single_thread`'s input
1.6.4=* Returns an array containing all return values of the called functions
1.6.4.1=* Any function calls that fail or return void will have a null return value
1.6.4.2=* Output order is NOT deterministic, and is reliant on whichever threads finish first.
1.7=* `__run_single_async_operation` -> int
1.7.1=* Similar to `__request_single_thread`, however returns an error code instead of the called function's output and will not block the calling thread.
1.7.2=* Used if you need to execute thread-safe code as soon as possible. Useful for render or server facing code.
1.7.3=* Returns `ERR_UNCONFIGURED` if the thread queue has reached the max size in the config, and `OK` in every other instance.
1.8=* `__run_multiple_async_operations` -> int
1.8.1=* Similar to `__request_multiple_threads`, however returns an error code instead of the output array and will not block the calling thread.
1.8.2=* Used if you need to execute thread-safe code as soon as possible. Useful for render or server facing code.
1.8.3=* Returns `ERR_UNCONFIGURED` if the thread queue has reached the max size in the config, and `OK` in every other instance.
